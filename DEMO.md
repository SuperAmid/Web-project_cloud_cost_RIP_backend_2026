# Краткий порядок показа ЛР‑1

1. Запустите MinIO и приложение по инструкции из README.
2. Откройте `/provider_routers/feed`: покажите видео, короткое описание в две строки, нативное «Ещё», пропускную способность, стоимость, лайки и красную иконку «Следующий» справа.
3. В адресной строке покажите `GET /provider_routers/feed?id=102` и `GET /provider_routers/feed?id=102&next=true`.
4. Откройте `/provider_routers/draft`: сначала два поля выбора из проводника — фото и видео, далее название и только два тематических параметра. Форма не сохраняет данные и не отправляет POST.
5. Откройте `/provider_routers`: передвиньте числовой слайдер минимальной пропускной способности и нажмите красную кнопку «Фильтровать». Покажите GET-параметр `minBandwidthMbps`.
6. Отметьте, что удалённая и черновая записи не выводятся на ленте и в плитке, а медиа по умолчанию берётся из MinIO по отдельным ключам изображения и видео.
