# Демонстрация ЛР2

1. Запустите Docker, примените `migrations/001_init.up.sql` и импортируйте `db/seed.sql` через Adminer.
2. Покажите таблицы и `SELECT` в Adminer.
3. Покажите feed, draft и grid; примените фильтр пропускной способности.
4. Создайте черновик через «Далее», заполните его и опубликуйте через ORM.
5. Удалите опубликованный маршрутизатор кнопкой в grid: это raw SQL `UPDATE`, а не физический DELETE.
6. Откройте URL удалённого маршрутизатора: должен быть 404. В grid удалённая запись отсутствует.
7. Покажите fallback-медиа, модели, миграции, seed и `MANUAL_SCREENSHOTS.md`.
