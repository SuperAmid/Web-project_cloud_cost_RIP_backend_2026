# Порядок показа ЛР‑2

1. В Docker Desktop покажите работающие `postgres`, `adminer`, `minio` и `minio-init`.
2. В Adminer откройте БД `provider_routers`; покажите `provider_routers`, `provider_router_users`, `provider_router_likes` и SQL `SELECT` опубликованных записей.
3. Откройте `/provider_routers/feed`: видео, двухстрочное описание с «Ещё», пропускная способность, стоимость, лайк и красная иконка следующей записи.
4. Откройте `/provider_routers`: передвиньте числовой слайдер и нажмите красную кнопку «Фильтровать». Покажите GET-параметр `minBandwidthMbps`.
5. Откройте `/provider_routers/draft`: фото и видео выбираются через проводник; далее вводятся имя, пропускная способность и стоимость. Нажмите «Далее» — черновик создаётся через GORM.
6. У черновика нажмите «Опубликовать», затем покажите новую запись в ленте и `SELECT` в Adminer.
7. В плитке нажмите «Логически удалить». Покажите, что карточка пропала, а в БД статус изменился на `deleted`; используемый в коде запрос — `UPDATE provider_routers SET status = ...`.
