# Отчёт 02 — лента: короткое описание, параметры и иконки справа, «Следующий» иконкой

Замечание: «лента: внизу описание сделать короткое — 2 строки до „Еще“ (без JS). Параметры
и обе иконки сделать справа. „СЛЕДУЮЩИЙ“ сделать иконкой».

## Было

`feed.html`: заголовок → описание → две метрики в ряд → строка действий,
где «Следующий» был текстовой кнопкой-ссылкой.

## Стало

- Контент ленты разбит на две колонки (`feed-layout`):
  - слева — заголовок (тип · номер, название);
  - справа — метрики (пропускная способность, потребление) и обе иконки:
    лайк `♥ N` и кнопка «Следующий».
- Описание перенесено вниз (футер ленты) и обрезано CSS до двух строк
  (`-webkit-line-clamp: 2`) без JavaScript.
- Раскрытие полного описания — без JS, тег `<details>` с заголовком «Еще».
- Ссылка «Следующий» стала круглой иконкой-стрелкой (`→`) вместо текста.

## Файлы

- `templates/feed.html` — новая структура `feed-layout` / `feed-head` / `feed-side` /
  `feed-icons` / `feed-foot` / `desc-more`.
- `static/styles.css` — сетка двух колонок, обрезка описания на 2 строки,
  стили `<details>`, иконки лайка и «Следующий».

## Проверка

`/provider-routers/feed` — описание внизу в 2 строки, «Еще» раскрывает полный текст
без JS; метрики и иконки ♥ / → справа; стрелка ведёт «следующий» через `?next=true`.
