# provider_routers — ЛР‑1

Учебное SSR-приложение на Go по теме «Маршрутизаторы провайдера». Код, URL и модель используют единое имя `provider_routers`.

## Предметная область

У каждого маршрутизатора два параметра по теме:

- пропускная способность, Мбит/с;
- стоимость, ₽.

Лента показывает один опубликованный маршрутизатор. Плитка показывает только опубликованные записи и фильтрует их по минимальной пропускной способности. Черновик доступен на отдельной странице; удалённая запись нигде не выводится.

## Дизайн

- все кнопки красные, прямоугольные, с небольшим скруглением;
- карточки белые с серой обводкой;
- нижняя навигация фиолетовая;
- на ленте описание ограничено двумя строками; полный текст раскрывается нативным элементом «Ещё», без JavaScript;
- «Следующий» — красная кнопка-иконка.

## Запуск

```powershell
docker compose up -d minio
$env:MINIO_PUBLIC_URL = 'http://localhost:9000/provider-media'
go run .
```

Откройте `http://localhost:8080/provider_routers/feed`.

MinIO Console: `http://localhost:9001` (`minioadmin` / `minioadmin`). Медиа лежат в бакете `provider-media`: ключи изображения и видео хранятся в модели отдельно.

## URL ЛР‑1

| Экран | URL |
| --- | --- |
| Лента | `http://localhost:8080/provider_routers/feed` |
| Лента по ID | `http://localhost:8080/provider_routers/feed?id=102` |
| Следующий опубликованный | `http://localhost:8080/provider_routers/feed?id=102&next=true` |
| Добавление/черновик | `http://localhost:8080/provider_routers/draft` |
| Плитка | `http://localhost:8080/provider_routers` |
| Фильтр-слайдер | `http://localhost:8080/provider_routers?minBandwidthMbps=10000` |

В ЛР‑1 используются только GET-маршруты. На странице добавления два файловых поля открывают проводник: фото и видео. До нажатия «Далее» данные не отправляются, а показанное по умолчанию медиа берётся из MinIO по ключам текущего черновика.
