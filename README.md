# provider_routers — ЛР‑1

Учебное SSR-приложение на Go по теме «Маршрутизаторы сети провайдера». Код, URL, модель и ключи медиа используют единое имя `provider_routers`.

## Предметная область

У каждого маршрутизатора два параметра по теме:

- пропускная способность, Мбит/с;
- стоимость, ₽.

Лента показывает один опубликованный маршрутизатор. Плитка показывает только опубликованные записи и фильтрует их по минимальной пропускной способности. Черновик доступен на странице добавления; удалённая запись нигде не выводится.

## Запуск

```powershell
docker compose up -d
go run .
```

Откройте `http://localhost:8080/provider_routers/feed`.

MinIO Console: `http://localhost:9001` (`minioadmin` / `minioadmin`). Медиа лежат в бакете `provider-media`; ключи изображения и видео хранятся в модели отдельно (`ImageKey`, `VideoKey`), URL собирается из `MINIO_PUBLIC_URL` (по умолчанию `http://localhost:9000/provider-media`).

Образы MinIO — `bitnamilegacy/minio` и `bitnamilegacy/minio-client`, закреплённые по версии и digest: официальные `quay.io/minio/*` стали приватными. Готовность MinIO проверяет `healthcheck`, а загрузка медиа (`minio-init`) стартует только после `service_healthy`.

## URL ЛР‑1

| Экран | URL |
| --- | --- |
| Лента | `http://localhost:8080/provider_routers/feed` |
| Лента по ID | `http://localhost:8080/provider_routers/feed?id=102` |
| Следующий опубликованный | `http://localhost:8080/provider_routers/feed?id=102&next=true` |
| Добавление/черновик | `http://localhost:8080/provider_routers/draft` |
| Плитка | `http://localhost:8080/provider_routers` |
| Фильтр-слайдер | `http://localhost:8080/provider_routers?minBandwidthMbps=10000` |

В ЛР‑1 используются только GET-маршруты. На странице добавления два файловых поля открывают проводник: фото и видео. Над ними показаны фото и видео черновика по умолчанию из MinIO. До нажатия «Далее» данные не отправляются.
