# Расчёт нагрузки на сеть провайдера

Учебный проект по дисциплине «Разработка интернет-приложений» (РИП).

## Предметная область

Система описывает сеть маршрутизаторов провайдера: центральные, промежуточные и конечные узлы жилых домов. Основная сущность — маршрутизатор. В дальнейших работах заявка будет рассчитывать нагрузку для маршрутизаторов в топологии «звезда/снежинка», где у каждого нижестоящего узла указан один мастер-маршрутизатор.

## Технологии

- Go;
- серверная HTML-шаблонизация (SSR);
- PostgreSQL, Adminer и MinIO в Docker — с лабораторной работы №2;
- REST API (JSON) с ORM GORM, проверка через Postman/Insomnia — с лабораторной работы №3;
- JWT, Redis и Swagger — с лабораторной работы №4.
