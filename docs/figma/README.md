# Экспорты макета ЛР1

В этой папке сохранены SVG-экспорты трёх экранов `provider_routers`: лента, добавление и плитка маршрутизаторов.

Настоящий файл `.fig` намеренно не подменяется SVG. Перед сдачей создайте или откройте Figma-макет по спецификации `../figma-lab1-spec.md` и приложите ссылку либо исходный файл Figma.
