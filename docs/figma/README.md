# Экспорты макета ЛР1

В этой папке сохранены SVG-экспорты трёх экранов: лента, добавление и плитка маршрутизаторов.

Настоящий файл `.fig` намеренно не подменяется SVG. Перед сдачей необходимо создать или открыть Figma-макет по спецификации `../figma-lab1-spec.md` и приложить ссылку либо исходный файл Figma.
