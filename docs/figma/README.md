# Экспорты макета

SVG-экспорты трёх экранов `provider_routers` размером 390×844:

| Файл | Экран |
| --- | --- |
| `01-feed.svg` | лента: видео, слева название и описание, справа параметры, лайк и «Следующий» |
| `02-draft.svg` | добавление: сверху фото и видео, ниже текст и поля |
| `03-routers.svg` | плитка маршрутизаторов со слайдером-фильтром |

Цвета взяты с сайта-источника «Ростелеком»: `#7700FF`, `#FF4F12`, `#101828`. Исходный макет — в Figma; при сдаче показывается сам макет, эти файлы — его экспорт.
