# Контрольные вопросы ЛР‑2

## Виды БД и SQL

PostgreSQL — реляционная БД: данные хранятся в связанных таблицах, а запросы пишутся на SQL. DDL создаёт структуру (`CREATE`), DML меняет данные (`INSERT`, `UPDATE`, `DELETE`), `SELECT` читает данные.

## Курсор

Курсор обрабатывает результат запроса построчно. Для логического удаления одной записи он не нужен: в проекте применяется параметризованный `UPDATE provider_routers SET status = ...`.

## ORM, модель и миграция

ORM сопоставляет Go-структуры с таблицами. GORM использует модели `ProviderRouter`, `ProviderRouterUser`, `ProviderRouterLike`; миграция описывает схему SQL, а `AutoMigrate` применяет её при старте. Создание и публикация черновика происходят через ORM.

## Чистая архитектура

Модели отвечают за предметные данные, handlers — за HTTP-сценарии, шаблоны — за отображение, а GORM/PostgreSQL — за хранение. Такое разделение позволяет изменить интерфейс или БД без изменения сути предметной области.
