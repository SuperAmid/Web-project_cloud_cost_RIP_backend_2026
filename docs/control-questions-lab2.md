# Контрольные вопросы ЛР2

## Виды БД и SQL

Реляционная БД хранит данные в таблицах со связями и SQL: PostgreSQL — реляционная БД. Документные БД хранят документы, key-value БД — пары ключ-значение, графовые — вершины и связи. SQL делят на DDL (`CREATE`, `ALTER`), DML (`SELECT`, `INSERT`, `UPDATE`, `DELETE`) и DCL (`GRANT`).

## Курсор

Курсор — механизм поочерёдной обработки строк результата запроса. Он нужен для построчной серверной логики, но для одного обновления статуса в ЛР2 достаточно параметризованного `UPDATE`.

## ORM, модель и миграция

ORM сопоставляет структуры языка с таблицами и формирует SQL. GORM связывает `Router`, `ProviderUser`, `RouterLike` с PostgreSQL. Модель описывает структуру данных и связи; миграция создаёт или изменяет эту структуру. В проекте `AutoMigrate` создаёт таблицы, а SQL partial index гарантирует один черновик на создателя.

## Чистая архитектура

Чистая архитектура отделяет бизнес-модель от инфраструктуры и интерфейса. Здесь модели маршрутизатора и пользователей независимы от HTML, handlers отвечают за HTTP, а GORM/PostgreSQL — за хранение. Это упрощает замену UI или хранилища без переписывания предметных правил.
