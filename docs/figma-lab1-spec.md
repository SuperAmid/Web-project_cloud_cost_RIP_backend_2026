# Макет Figma для ЛР‑1: provider_routers

Создать три мобильных экрана 390 px: лента, добавление и плитка. Все подписи и адреса используют `provider_routers`.

## Единый стиль

- фон страницы: `#F5F5F5`;
- карточки: белые, обводка `#B9B9B9`;
- кнопки: красные `#D92D20`, прямоугольные, радиус 5 px;
- навигация снизу: фиолетовая `#5B2C83`;
- основной текст: `#27272A`.

## Лента

Большая карточка с видео и затемнением. Внизу: название, короткое описание максимум на две строки и нативное «Ещё». Справа расположить пропускную способность, стоимость, лайк и красную иконку-стрелку «Следующий». Не размещать параметр энергопотребления.

## Добавление

Поля идут сверху вниз: фото (выбор из проводника), видео (выбор из проводника), название, пропускная способность, стоимость и кнопка «Далее». До «Далее» нет отправки на сервер. Под файлами указать, что по умолчанию изображение и видео берутся из MinIO по разным ключам.

## Плитка

Сверху числовой слайдер «Минимальная пропускная способность» и красная кнопка «Фильтровать». Ниже белые карточки с серой границей: изображение, название, пропускная способность, стоимость и лайки. Нижняя навигация фиолетовая.
