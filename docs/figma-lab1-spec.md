# Спецификация макета Figma — ЛР1

В Figma создаётся один файл `provider-router-lab1.fig` с тремя фреймами `390 × 844 px` в портретной ориентации. В репозитории сохранены только SVG-экспорты фреймов в `docs/figma/`; они не являются и не заменяют файл Figma.

## Референс и палитра

- Референс: Ubiquiti; использованы компактные технические карточки, холодная тёмная поверхность и голубой акцент.
- Background: `#07131F`.
- Primary: `#0D79F2`.
- Accent: `#58E1FF`.

## Фреймы

1. **Лента**: карточка-видео `358 × 746`, радиус 25; затемняющий градиент снизу; сверху тип, название и описание, две метрики, внизу ♥ 3 и кнопка «Следующий». Панель навигации высотой 64.
2. **Добавление**: заголовок, изображение `358 × 140`, десять полей формы с интервалом 13, заметка «не сохраняется», та же нижняя панель.
3. **Маршрутизаторы**: заголовок, input фильтра и button; две карточки в ряд по 173 px с gap 12, изображение 110 px, название, тип, пропускная способность и лайки.

## Состояния

У карточек hover: смещение вверх на 3 px и border `#58E1FF`. У кнопки фильтра и «Следующий» hover: primary изменяется на `#3395FB`.

Тексты должны совпадать с реализацией: Core Backbone One, North Ring Hub, Harbor Residence Gateway и Riverside Residence Gateway.
