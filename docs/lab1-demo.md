# ЛР‑1: что показать преподавателю

1. `GET /provider_routers/feed` — опубликованная запись, видео, описание до двух строк и «Ещё» без JavaScript.
2. `GET /provider_routers/feed?id=102` и `GET /provider_routers/feed?id=102&next=true` — выбор записи и переход к следующей.
3. `GET /provider_routers/draft` — фото и видео выбираются через проводник; по умолчанию оба медиа берутся из MinIO. Далее указаны название, пропускная способность и стоимость; `Далее` не отправляет форму.
4. `GET /provider_routers` — белые карточки с серой границей, фиолетовая навигация, красные кнопки.
5. `GET /provider_routers?minBandwidthMbps=10000` — серверная фильтрация по числу из слайдера. JavaScript и POST отсутствуют.
